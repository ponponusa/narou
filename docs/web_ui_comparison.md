# Web UI 機能対応表（Legacy vs Astro版）

このドキュメントは、Legacy Web UI（Sinatra + HAML版）とAstro版Web UI（Astro + Svelte 5版）の機能対応状況を比較した一覧表です。

**最終更新日**: 2025-11-20

## 凡例

- ✅ **実装済み**: 完全に実装されている
- 🟡 **部分実装**: 一部のみ実装、または機能が限定的
- ❌ **未実装**: まだ実装されていない
- 🔄 **代替実装**: 異なる方法で同等機能を提供
- N/A **対象外**: Astro版では実装予定なし

## まとめ

Astro版Web UIは、Legacy版の主要機能（約60%）を実装済みです。特に小説管理の基本操作、タグ管理、タスクキュー管理、設定編集といったコア機能は完全に動作しています。

未実装機能の多くは特殊用途（ブックマークレット、Kindle連携、メール送信等）やエッジケース（範囲選択モード、個別メニュー編集等）であり、日常的な小説管理作業には支障ありません。

今後は、高優先度機能（小説個別設定、置換パターン、ショートカットキー）から順次実装し、Legacy版と同等以上の機能性を目指します。
