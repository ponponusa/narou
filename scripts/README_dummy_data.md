# ダミーデータ生成スクリプト

## 概要

開発・テスト用のダミー小説データを生成するスクリプトです。
`.narou/database.yaml` と `小説データ/` ディレクトリにダミーデータを追加します。

## 使用方法

### ダミーデータ生成

```bash
# デフォルト（10000件）生成
ruby scripts/generate_dummy_data.rb

# 任意の件数を指定
ruby scripts/generate_dummy_data.rb 5000
```

### ダミーデータ削除

```bash
ruby scripts/generate_dummy_data.rb cleanup
```

## 生成されるデータ

### データベース (`.narou/database.yaml`)

- 小説メタデータ（タイトル、著者、サイト情報など）
- 全てのデータに `dummy` タグが付与される
- 対応サイトからランダムに選択:
  - `ncode.syosetu.com` (小説家になろう)
  - `novel18.syosetu.com` (小説家になろう 18禁)
  - `kakuyomu.jp` (カクヨム)

### 小説ファイル (`小説データ/<ID>/`)

各小説ごとに以下のファイルが生成されます:

- `setting.ini` - 設定ファイル
- `toc.yaml` - 目次データ
- `<N>.html` - エピソードファイル（最大5話分）

## 特徴

- **増分追加**: 既存データを保持したまま新規データを追加
- **ランダム生成**: サイト、著者、タイトル、タグなどをランダムに組み合わせ
- **タグ識別**: 全データに `dummy` タグを付与（削除時の識別用）
- **高速処理**: 10000件の生成が約50秒で完了

## 生成例

```
Title: 勇者パーティーを追放されたので自由に生きることにした #0
Author: 中村麻美
Site: ncode.syosetu.com
Tags: dummy, バトル, 異世界転生, 恋愛, 学園
Ncode: N7042PC
Episodes: 111
```

## サイト別分布（10000件生成時の例）

```
ncode.syosetu.com: 3454件
novel18.syosetu.com: 3326件
kakuyomu.jp: 3220件
```

## 注意事項

- `cleanup` コマンドは `dummy` タグを持つ全データを削除します
- 削除前に確認プロンプトが表示されます
- 既存の実データには影響しません（`dummy` タグがない限り）

## パフォーマンス

- 10000件生成: 約45秒 + 書き出し約3秒
- データベースサイズ: 約12MB（10000件）
- 小説ディレクトリ数: 10000個
